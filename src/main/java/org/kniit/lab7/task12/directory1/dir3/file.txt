Быстро пролетело жаркое лето. Часто моросит мелкий дождь. По небу поползли
серые тучи. На лесной поляне порыжела трава. В лужах плавают осенние листья.
Хмуро темнеет среди травы муравьиная куча. Муравьи начали уходить в свои
жилища. Они редко теперь выползают наружу. Возле старого пня росли два
подосиновика. Шляпки грибов весело глядели из травы. Их заметила белка. Она схватила
один гриб и скрылась.
